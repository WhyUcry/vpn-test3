## 🚀 ДЕПЛОЙ НА СЕРВЕР

### Шаг 1: Закоммитьте и запушьте изменения

```bash
# На вашем компьютере
git commit -m "feat: fix payment notifications, add landing page, and UI improvements"
git push origin main
```

### Шаг 2: Обновите сервер

```bash
# Подключитесь к серверу
ssh root@213.189.222.68

# Перейдите в проект
cd ~/dudonya-vpn

# Остановите контейнеры
docker compose down

# Получите изменения
git pull origin main

# ВАЖНО: Запустите миграцию (добавляет таблицу notifications)
docker compose run --rm backend python scripts/migrate_add_notifications.py
```

**Ожидаемый вывод:**
```
Creating notifications table...
✅ Notifications table created successfully
```

### Шаг 3: Пересоберите и запустите

```bash
# Пересоберите образы (ВАЖНО для обновления кода бота!)
docker compose build --no-cache bot backend

# Запустите
docker compose up -d

# Проверьте статус
docker compose ps
```

**Всё должно быть Up:**
```
dudonya-backend   Up (healthy)
dudonya-bot       Up
dudonya-caddy     Up
```

### Шаг 4: Проверьте логи

```bash
docker compose logs -f
```

**Ищите в логах:**
- ✅ Backend: `Backend started successfully`
- ✅ Bot: `Notification service started`
- ✅ Caddy: `certificate obtained successfully`

**Нажмите Ctrl+C для выхода**
